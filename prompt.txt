MINI PROJECT – PROMPT HISTORY

Project Title: 2D Graphics Editor Using C

==================================================
DAY 1

Prompt:
Write a C program for a simple 2D Graphics Editor. Use a 2D character array as a canvas. Create a menu-driven program with the following options:

1. Add Object
2. Delete Object
3. Modify Object
4. Display Picture
5. Exit

Implement functions to clear the canvas and display the canvas. Store the picture using a 2D array of characters.

Response:
Generated a Day 1 program containing:

- 2D character array canvas
- clear_canvas() function
- display_canvas() function
- Menu-driven interface
- Placeholder options for Add, Delete, and Modify

==================================================
DAY 2

Prompt:
Extend the 2D Graphics Editor. Implement functions to draw the following shapes using ASCII characters:

- Line
- Rectangle
- Circle
- Triangle

Store shapes using structures and assign unique IDs. Allow users to add shapes to the canvas and redraw all shapes whenever a new object is added.

Response:
Generated a Day 2 program containing:

- Shape structure
- ShapeType enumeration
- draw_line()
- draw_rectangle()
- draw_circle()
- draw_triangle()
- render_all_shapes()
- add_shape()
- Shape ID management
- Canvas rendering

==================================================
DAY 3

Prompt:
Further extend the 2D Graphics Editor. Implement:

- Delete Object
- Modify Object

Allow the user to delete an object using its Shape ID and modify an object's coordinates using its Shape ID. Redraw the canvas whenever a shape is modified or deleted. Maintain the menu-driven interface.

Response:
Generated a Day 3 program containing:

- delete_shape()
- modify_shape()
- Shape ID lookup
- Updated rendering logic
- Updated menu system
